# Adeel Rashid — Lead Generation & Email Marketing Portfolio

A professional portfolio website for GitHub Pages.

## Included
- Responsive portfolio website (`index.html`)
- Project showcase image (`images/lead-generation-showcase.png`)
- README for GitHub visitors
- Fictional sample lead list (`sample-leads.csv`)

## Publish with GitHub Pages
1. Create a new **public** repository named `adeel-rashid-portfolio`.
2. Upload all files and keep the `images` folder structure intact.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then save.
6. After GitHub Pages publishes the site, copy the URL shown in Settings → Pages.

The showcase image is an illustrative mockup. Its example records are not real client results or verified leads. The CSV uses fictional sample data only. Update contact details before publishing.
